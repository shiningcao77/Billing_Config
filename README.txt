MPS Billing Workflows

Open index.html in a web browser. No installation or build step is required.

Files
index.html: page structure
style.css: visual styles
app.js: workflow and interactions
assets.js and original-assets.js: asset references
assets/: original icons, chart assets, and font

Includes description dropdowns and threshold percentage choices from 10% to 100%.
Budget data is stored in your browser using localStorage. This is a prototype and does not connect to Google Cloud.
